## Integration path

The GOAT plan's CLI talks to a private `POST https://api.commandcode.ai/alpha/generate` request body, and `/v1/models`, `/openai/v1/models`, `/alpha/models`, and `/v1/chat/completions` on that host answered 404.
Provider API access is a separately priced plan, and bring-your-own-key routes outside providers into Command Code rather than exposing it, so Pi or opencode cannot reach GOAT models as an OpenAI-compatible provider.
The adapter is therefore a native harness.

## Observed vendor surfaces

Once the TUI starts, the node bundle sets its process title so `ps -o comm=` reports `command-code`.
`--list-models` prints one model id per line in its first column, including `deepseek/deepseek-v4.1-flash`.
`--yolo --skip-onboarding --no-auto-update` with a prompt argument started an interactive turn without a permission, onboarding, or update dialog.
CLI `--effort` wrote `reasoningEffort` into `~/.commandcode/config.json`, so the launch never passes it.
A `--mod` file loaded regardless of workspace trust; its `cmd.setEffort` changed only the session, and the transcript recorded `"effort":"high"` while the user config stayed byte-identical.
The mod received `run_start`, `turn_end`, and `run_end`, and `run_end` also fired for an interrupted run.

The idle composer is a `❯` row between two solid `─` rules holding `Ask your question...`.
Its first letter is the reverse-video cursor cell `\e[7mA\e[0m`, and the rest uses RGB `138;148;168`, bright enough to pass the shared dim-ghost ceiling.
Typed text uses the default foreground followed by the reverse-video cursor cell.
An inherited `NO_COLOR=1` removes the cursor cell, so the launch clears it.
The terminal cursor rests on a blank row below the `» permission bypass on [shift+tab]` and `? for shortcuts` status rows, not on the composer.
A running turn renders `<spinner> <verb>…  esc to interrupt • 2s • ↓ 0`, with longer runs as `2m 8s`; a styled capture splits that hint across SGR runs, while the plain capture used by delivery keeps it whole.
One Escape on a running turn rendered `Interrupted · What should Command Code do instead?` and an empty composer; Escape on an idle composer changed nothing.
Enter while a run is busy queued the text on a `›` row and ran it in the same run as another turn.
`/exit` returned to the shell and printed `commandcode --resume <session-id>`.

## Workspace files and attribution

Command Code creates `.commandcode/taste/taste.md` in every workspace it opens.
Settings resolve from `.commandcode/settings.local.json`, then `.commandcode/settings.json`, then `~/.commandcode/settings.json`.
The local file's `"mods":{"disabled":["learning"]}` disables taste learning, and `"attribution":{"commit":""}` removes the default `Co-authored-by: CommandCodeBot <noreply@commandcode.ai>` trailer.
The guard's worker commit carried no co-author trailer, and `git status --porcelain` showed no `.commandcode` path.
