# Firstmate instruction inbox
Firstmate steers you through durable message files in '{run-worktree}/.doorbell-check.5JItYv/brief-home/state/brief-task.inbox'.
When a terminal message says an instruction is waiting there - and at any natural checkpoint when you are unsure - list '{run-worktree}/.doorbell-check.5JItYv/brief-home/state/brief-task.inbox'/*.msg, read and act on each message in numeric order, then acknowledge each handled message with `'{run-worktree}/bin/fm-inbox-ack.sh' 'brief-task' <seq>` (usage is in that script's header; `'{run-worktree}/bin/fm-inbox-ack.sh' 'brief-task' --all-handled-through <seq>` acknowledges a whole run); never move the files by hand.
That command is the acknowledgement: without it firstmate rings again and eventually treats you as stuck. An empty or absent inbox needs no action.
